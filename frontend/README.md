# Frontend

Le frontend de PRIICE sera développé en React avec TypeScript.

Fonctions prévues :

- tableau de bord ;
- création et consultation des investigations ;
- fiches d’entités ;
- navigation par pivot ;
- visualisation des relations ;
- timeline ;
- consultation des sources ;
- génération et consultation des rapports.

La priorité UX est de rendre simple une investigation potentiellement complexe.
