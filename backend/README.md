# Backend

Le backend de PRIICE sera développé en Python avec FastAPI.

Responsabilités prévues :

- API REST ;
- dossiers d’investigation ;
- entités et relations ;
- provenance des données ;
- orchestration des connecteurs ;
- normalisation ;
- reporting ;
- authentification et contrôle d’accès minimal.

Le code applicatif sera ajouté progressivement pendant le S1.
