# Cadre éthique et légal

PRIICE est destiné à l’exploitation d’informations accessibles dans un cadre légitime depuis des sources ouvertes.

## Principes

- conserver la provenance des informations ;
- distinguer fait, hypothèse et relation rejetée ;
- permettre une validation humaine des rapprochements sensibles ;
- minimiser les données stockées ;
- respecter les conditions d’accès des sources utilisées ;
- documenter les limites des connecteurs et les incertitudes.

## Hors périmètre

PRIICE n’est pas conçu pour :

- contourner un compte privé ou une authentification ;
- contourner des restrictions techniques d’accès ;
- collecter des mots de passe ou secrets ;
- exploiter des données volées ;
- automatiser du harcèlement ou du doxxing ;
- présenter une corrélation comme une preuve sans justification.

## Démonstrations

Les scénarios de démonstration privilégient :

- des identités fictives ;
- des jeux de données dédiés ;
- les membres de l’équipe avec leur accord ;
- des informations publiques adaptées à un usage pédagogique.
