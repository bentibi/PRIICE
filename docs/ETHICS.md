# Cadre d’utilisation de PRIICE

PRIICE est destiné à l’exploitation d’informations accessibles dans un cadre légitime depuis des sources ouvertes.

## PRIICE n’est pas conçu pour

- contourner des comptes privés ;
- contourner une authentification ou un contrôle d’accès ;
- collecter des mots de passe ou secrets ;
- exploiter des données volées ;
- automatiser du harcèlement ;
- faciliter le doxxing.

## Principes

- conserver la provenance des informations ;
- distinguer faits, hypothèses et relations rejetées ;
- permettre la vérification d’une conclusion ;
- limiter la collecte aux données utiles au scénario ;
- utiliser pour les démonstrations des jeux de données contrôlés, fictifs ou publics adaptés.
