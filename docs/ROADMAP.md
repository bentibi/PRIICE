# Roadmap PRIICE

## Semestre 1 — PRIICE Core

Objectif : obtenir un MVP fonctionnel permettant de mener une investigation de bout en bout.

### Cadrage
- benchmark et expression du besoin ;
- architecture ;
- modèle de données ;
- maquettes UX ;
- backlog et critères d’acceptation.

### Socle produit
- dossiers d’investigation ;
- entités ;
- relations ;
- sources et provenance ;
- notes analyste ;
- statuts et niveau de confiance.

### Collecte
- framework de connecteurs ;
- au moins 5 mécanismes OSINT ;
- normalisation ;
- gestion des erreurs et limitations.

### Interface
- dashboard ;
- fiches d’entités ;
- navigation par pivot ;
- graphe filtrable ;
- consultation des sources.

### Reporting
- génération d’un rapport d’investigation sourcé ;
- export HTML puis PDF si possible.

### Industrialisation
- Docker Compose ;
- tests ;
- CI/CD ;
- documentation ;
- démo et soutenance.

## Semestre 2 — PRIICE Intelligence

- Entity Resolution ;
- déduplication avancée ;
- scoring de confiance explicable ;
- timeline enrichie ;
- recherche étendue de présence publique ;
- Threat Intelligence ;
- STIX ;
- collaboration ;
- watchlists et détection d’évolution ;
- rapports avancés ;
- API publique PRIICE.
